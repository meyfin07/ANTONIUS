# MultiLearn — Website Interaktif Multimedia

Website media pembelajaran dengan 6 menu:
1. Home
2. Materi
3. Quiz
4. Tugas
5. Video
6. Tentang

## Cara menjalankan
1. Extract folder.
2. Buka `index.html` menggunakan Chrome/Edge.
3. Tidak membutuhkan XAMPP atau database.

## Fitur
- Responsive desktop/mobile
- Navigasi 6 menu
- Animasi reveal
- Animasi floating
- Quiz 10 soal dengan nilai otomatis
- Form tugas dan validasi
- Video YouTube
- Desain modern ungu-biru
- Tombol kembali ke atas

## Kustomisasi
Edit identitas pada bagian `Tentang` di `index.html`.
Ganti URL video pada `<iframe>` jika ingin menggunakan video YouTube lain.

## Catatan
Folder `assets/images`, `assets/audio`, dan `assets/video` disiapkan untuk menambahkan file multimedia lokal.


## Multimedia lengkap (V4)
- 3 gambar ilustrasi lokal di `assets/images/`
- Musik instrumental original lokal di `assets/audio/musik_belajar.wav`
- Tombol Play/Pause musik di Home
- Galeri gambar multimedia
- Semua aset ikut di-upload ke hosting.
- Autoplay musik tidak digunakan karena browser biasanya memblokir audio otomatis.
